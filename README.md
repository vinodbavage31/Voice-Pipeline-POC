# Voice RAG Prototype

## Prerequisites
- Docker
- Docker Compose

## Quickstart
1. `copy .env.example .env`
2. `docker-compose up -d --build`
3. Frontend: http://localhost:5173
4. Backend API: http://localhost:8000
